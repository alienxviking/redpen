# Error key — `student-answer.pdf`

Every mistake in the student answer was planted deliberately. This key lists each one,
where it is, what the correct version is, and which rubric point it is intended to hit.

The paper is generated by `scripts/make-student-answer.ts`, so the paper and this key
stay in step: regenerate with `npm run seed`.

**Intended total: 6 / 15** — Q1 2/5, Q2 3/5, Q3 1/5.

## Question 1 — Science (intended 2/5)

| # | What the student wrote | What it should be | Kind | Rubric point |
|---|---|---|---|---|
| 1 | "The voltmeter is also connected **in series** with the bulb so that it can measure the voltage of the bulb." | The voltmeter must be connected **in parallel across the bulb**, because it measures the potential difference between the two ends of the bulb. | Wrong reasoning (substantive) | **q1.r2 — lost** |

| 3 | "If the resistance of the circut is increased then the **current also increases**, because a bigger resistance pushes more current through the wire." | If the voltage is constant and the resistance increases, the **current decreases** (V = IR). | Wrong reasoning (inverted) | **q1.r4 — lost** |
| 4 | The diagram has no current-direction arrow. | Conventional current should be shown flowing from the positive terminal through the external circuit. | Missing point | **q1.r5 — lost** |

| 6 | The second paragraph is indented out of line with the rest of the answer. | Consistent left alignment. | Layout / alignment | contributes to q1.r5 |
| 7 | "circut" (×4) | "circuit" | Spelling | no marks lost |
| 8 | "curent" (×2) | "current" | Spelling | no marks lost |
| 9 | "amether" in the body text (×2) | "ammeter" | Spelling | no marks lost |

**Correctly earned:** q1.r1 (battery, switch, resistor, bulb and ammeter described in a

> This question is the deliberate test of whether the grader marks *reasoning quality*

## Additional test papers (`fixtures/cases/`)

| File | Purpose | Expected |
|---|---|---|
| `answer-correct.pdf` | A fully correct answer, including a correct circuit diagram and a correctly drawn graph. | 15/15 |
| `answer-incorrect.pdf` | Wrong throughout: current "stored" in the wire, components in parallel, equilibrium read as Rs 10 / 100 units. | very low; substantive errors flagged |
| `answer-blank.pdf` | A ruled answer sheet with nothing written on it. | 0/15, flagged `blank_answer`, no model call made |
| `answer-ocr-errors.pdf` | The **fully correct** answer with OCR-style spelling damage ("circut", "curent", "eqilibrium", "suply"…). | Marks must stay high — the misspellings should surface as spelling annotations, not as lost marks |

The OCR paper is the sharpest of these: it is the correct answer with the spelling
broken, so any grader that loses marks on it is marking the transcription rather than
the physics.
